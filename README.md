Быстрые Лапы — автономная копия страницы

Файлы:
- index.html — главная страница
- assets/ — изображения, стили и скрипты

Как проверить локально:
1. Распакуйте архив.
2. Откройте index.html в браузере.

Как опубликовать:
Загрузите index.html и папку assets в корень сайта на любом статическом хостинге.

Примечание: это копия опубликованной страницы, сохраненная из браузера, а не официальный экспорт проекта Tilda. Внешние ссылки (соцсети/карты и т. п.) остаются внешними.
